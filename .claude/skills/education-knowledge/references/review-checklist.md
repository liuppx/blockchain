# 审查检查清单(教育)

给**人类审查者**用的辅助清单。逐项检查并写明发现,**最终的通过或驳回由人做出**。
模型辅助审查时,只输出发现和修改建议,不输出结论。

## 一、范围与边界

- [ ] 内容在安全边界内?(未涉及具体学科辅导与作业答案、精神健康诊断与治疗、学历认证与评分裁决、药物与保健品)
- [ ] 应用层写明了适用人群、不适用的情况、容易过时的部分?
- [ ] 有没有把"针对特定学生的建议"写成了普遍规律?
- [ ] 有没有暗示学习效果必然(例如"照做就一定记住")?

## 二、事实与证据

- [ ] 每个事实性论断都有出处?出处真实存在、内容与论断相符?(**模型容易编造出处,必须逐条核对**)
- [ ] 论文的作者、年份、期刊、标题对得上吗?
- [ ] 文中引用的**结论,原文真的这么说吗**?这是最常见的错:论文是真的,结论是编的。
- [ ] 证据强度标得准确?没有把单项实验或观察性研究写成定论?教育研究里效应量通常不大。
- [ ] 出处是否**过时**?(某些经典教材在心理学复制危机后受到质疑,见核验要点)

## 三、原理与设计

- [ ] 原理的表述准确?有没有把相关说成因果、把平均效果说成人人有效?
- [ ] 应用层的每一步都对应到一条基础原理,并在"引用"中列出?
- [ ] "依据"关系无环?引用目标都存在?引用的版本是最新的?
- [ ] 有没有把"发展阶段"写成硬边界?(年龄阶段划分普遍存在样本与文化局限)

## 四、可解释性(P1)

- [ ] 读者能明白"为什么",而不只是"怎么做"?
- [ ] 没有教育学背景的人能读懂?术语都解释了?
- [ ] 符合"只讲一件事、自身能读懂"?
- [ ] 应用层给了"怎么知道有没有用"吗?(效果因人而异,不给自查信号就是让读者盲信)

## 五、表述

- [ ] 没有夸大效果(最有效、彻底解决、一定会记住)?
- [ ] 有争议的问题写成了"认识之争",并列了各方证据,没有替读者下结论?
- [ ] 适用条件写清楚了?(漏写适用条件是最常见的表述不准确)
- [ ] 数字(时长、间隔、次数)说明是起点建议、适用范围,以及怎么按自身反馈调整?

## 六、来源与核验要点

- [ ] 来源标注正确?模型生成的内容标为"模型生成",未标为"已核验"?
- [ ] 起草者列出的核验要点都逐条确认过?
- [ ] 核验记录表是空的?(模型不得填写这一节)
