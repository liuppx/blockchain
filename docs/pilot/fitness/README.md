## 起草中发现需要补的基础单元

深蹲引用了以下原理,目前还没有对应的基础单元(见技能 `references/principles.md`):

- 超量恢复
- 核心稳定
- 关节的稳定与灵活
- 运动前自我评估(PAR-Q+)

这正好说明了四层结构的用法:**写一条应用知识,会自然暴露出它依赖、但还缺失的基础知识。**
